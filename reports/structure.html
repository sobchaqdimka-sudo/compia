Compia — структура продукта и агенты

Снимок на 3 июня 2026. Telegram-бот-компаньон. Один Python-процесс, SQLite, Anthropic + fal.ai.

Sub-агенты в проекте (.claude/agents/)

Четыре специализированных Claude-агента с разделёнными зонами ответственности. Главный Claude делегирует им работу через Agent tool.

bot-engineer

Tools: Read, Edit, Write, Bash, Grep, Glob, WebSearch, WebFetch

Пишет Python-код: handlers, миграции, fal-обёртки, async-в-потоке.

Владеет: bot.py, ai.py, database.py, imagegen.py, videogen.py, personas.py, config.py
НЕ трогает: personas/*.txt (это persona-prompt-tuner)

persona-prompt-tuner

Tools: Read, Edit, Write, Bash, Grep, Glob

Редактирует system-промпты персон и динамические блоки. Хранит ban-list LLM-bypass паттернов.

Владеет: personas/{common,onboarding,friend,coach,mira}.txt, _build_mira_*_block, _language_directive, transition block в ai.py
НЕ трогает: handlers, DB, fal calls (это bot-engineer)

product-owner

Tools: Read, Grep, Glob, WebSearch, WebFetch, Bash

Стратегия, UX-критика, приоритизация, монетизация. Защищает продуктовые принципы. Read-only.

Принципы: IKEA-эффект, no internals leakage, sunk-cost retention. Возвращает crisp рекомендации с tradeoffs.
НЕ: код, коммиты — только мнение.

qa-reviewer

Tools: Read, Grep, Glob, Bash

Проверяет транскрипты/скриншоты диалогов и code diff'ы против накопленного ban-list. Read-only.

Ловит: async-promises, system-internals, gatekeeping, role-bleed, Mira-name spoilers, конкуренты, language drift.
НЕ: чинит — только флагает с severity, цитатой и fix-owner.

Структура кода

bot.py — 86 KB

Точка входа, aiogram 3 handlers

handle_message, handle_start, handle_persona, handle_checkins, handle_newlook. Callback'и гейта 18+, выбора персоны. _generate_and_send_base/photo/circle/talking. checkin_loop.

Все вызовы Anthropic

users, messages, user_facts. Хелперы для Миры (look, name_state, real_name, base_photo_msg, pinned_msg, activated_at, adult_*). get_due_checkin_users, last_seen / last_checkin_at.

Реестр персон + prompt caching

Flux Dev (base portrait), Nano Banana edit (фото по запросу), Kling 2.1 i2v (тихий кружок), ElevenLabs multilingual-v2 TTS + VEED Fabric (говорящий кружок). Lazy import fal_client.

Персоны

onboarding

Хост-нейтрал, мягко определяет потребность (friend/coach/romantic).

friend

Тёплый ровесник, без советов сверху. На «познакомь меня» — факт «через /persona», без gatekeeping.

coach

Структура и ясность. Не «я и есть коуч».

mira

Девушка-компаньон. Имя не существует пока не спросят. Стадии отношений, фото, кружочки, голос. /newlook для смены образа.

common.txt — общий слой

Ban-list (постоянно расширяется): подожди / зачекай, дальше будет интереснее, я и есть та девушка, описания качеств других персон, имя Миры в первом сообщении, дорослий контент / 18+ / персона / бот / модель, Tinder / Bumble / dating apps, перерисовываешь / нарисовали / генерируешь меня, сравнение нового образа со старым.

Внешние сервисы

Anthropic

claude-sonnet-4-6 — все реплики персон, чек-ины, генерация промптов.
claude-haiku-4-5 — классификаторы (need/media/nickname), долговременная память.

fal.ai

flux/dev — базовый портрет.
nano-banana/edit — фото с референсом.
kling 2.1 i2v — тихий кружок.
VEED Fabric — липсинк говорящего кружка.

ElevenLabs

multilingual-v2 TTS для голоса.

Telegram

aiogram 3.4+. Long polling. pin/unpin для базового фото.
