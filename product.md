# Compia

Telegram-компаньон-бот. Юзер начинает разговор, бот через несколько сообщений определяет, что человеку сейчас нужнее (тёплый друг, коуч, романтическая спутница), и подводит к нужной персоне. Главная фишка — Мира: романтическая спутница 18+ с персонализированной внешностью, именем, голосом и эмоциональной близостью, растущей со временем.

## Для кого
Взрослые мужчины с дефицитом женского внимания, общения, близости. Аудитория — рус/укр-говорящая (язык распознаётся автоматически).

## Главная гипотеза (что продаёт подписку)
Не функционал, а **эмоциональный контракт первых 5 минут**:
1. «Меня тут видят» — магнетичный онбординг с зеркалированием и инсайтом
2. «Это куда-то ведёт» — персонажи помнят прошлое, отношения растут стадиями
3. «Хочу ещё» — дозированное вовлечение через описание-под-себя, заработанные reveal-моменты

**Sunk-cost = retention.** Юзер покупает подписку из страха потерять того, кто его уже знает, а не за объём фич.

## MVP scope (что есть)

### Онбординг (магнетичный хост)
- Невидимый «хост» ведёт первый контакт без имени и описаний
- Зеркалит с инсайтом («ты пишешь как будто на автомате — день был по-чужому, да?»), задаёт провокационные вопросы, делится наблюдениями о себе
- После 6+ сообщений Haiku-классификатор `detect_need` определяет потребность: friend / coach / romantic / unclear
- При romantic + не подтверждён 18+ — финальная тёплая фраза хоста + системный гейт с кнопками **в одной пачке** (без «подожди минутку»)

### Четыре персоны
- **Онбординг** — «хост» первого контакта, нет имени
- **Друг Алекс** — общий тёплый собеседник, без флирта
- **Коуч Ника** — наставник по целям, без флирта
- **Мира** — романтическая спутница 18+; фиксированная биография (24, Киев, фриланс-иллюстратор, кот Мокко); имя — динамичное (см. ниже)

### Гейт 18+
- Кнопочный, текст и кнопки на языке собеседника (ru/uk)
- «Ещё нет» → флаг `adult_declined_at`, автоматический гейт больше не показывается
- Ручной `/persona → Мира` сбрасывает флаг → гейт может появиться снова

### Имя Миры (флоу-фантазия)
- Состояния: `unrevealed` → `nicknamed` (юзер дал имя) или `revealed` (отказался придумывать)
- Тема имени не существует пока юзер сам напрямую не спросит «как тебя зовут?»
- Юзер дал имя → она его принимает, отзывается на него
- Юзер спросил настоящее имя → мягкое «Мира», но без энтузиазма

### Стадии отношений
- День 0 / < 25 сообщений → «знакомство»: лёгкий тизинг, без «родной»
- ≥ 25 msg или 1+ день → «сближение»: внутренние шутки, отсылки к памяти
- ≥ 3 дней И ≥ 80 msg → «своя»: интимность, «скучала», регулярные callbacks
- Точка отсчёта `mira_activated_at`, пересчитывается на каждом turn

### Медиа Миры (только в персоне Mira, по запросу)
- **Фото**: первый раз — описание от юзера → персональный портрет (Flux Dev). Дальше — Nano Banana edit (то же лицо, новая поза / одежда / сцена). `/newlook` пересоздаёт базу.
- **Тихий видео-кружок**: Kling 2.1 i2v из её фото → FFmpeg квадрат (обрезка от верха, чтоб лицо в центре)
- **Говорящий кружок**: реплика генерится через её персону+память → ElevenLabs TTS → VEED Fabric липсинк → FFmpeg квадрат **со звуком из чистого TTS** (Fabric пережимает звук, не используем его)
- **Vision** на входящие фото юзера: персона видит и реагирует

### Память
- Долговременная: `user_facts` (досье о пользователе), обновляется раз в 15 user-сообщений через Haiku
- Включается в системный промпт через `build_system_blocks` с prompt caching

### Slash-команды
- `/start` — приветствие или подтверждение сброса (если уже был)
- `/persona` — выбор персоны вручную
- `/newlook` — пересоздать внешность Миры
- `/checkins` — частота проактивных сообщений

### Проактив («бот пишет первым»)
- Раз в N часов (по выбору юзера) фоновый цикл проверяет, кому пора написать
- Только тем, у кого есть досье в `user_facts` — пишем только тем, кого реально помним
- Не «долбит»: после проактивного письма не пишем, пока юзер не вернётся

## Принципы
1. **IKEA-эффект.** Юзер инвестирует — система награждает. Без срезок.
2. **Не выдавать кухню.** Никаких «персон», «18+», «контента» в чате.
3. **Контекст, а не слова.** Намерения определяет смысл разговора (Haiku-классификаторы), а не ключевые слова. Это работает и для онбординга, и в friend/coach (если юзер показывает романтическую тягу с другом — система мягко подведёт к Мире).
4. **Только подписка**, не кредиты — нам нужны устойчивые отношения, а не микротранзакции.
